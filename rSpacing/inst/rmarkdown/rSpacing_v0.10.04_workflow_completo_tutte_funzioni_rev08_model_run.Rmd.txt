# Scopo

Questo documento usa **tutte le 77 funzioni esportate** da rSpacing 0.10.03, in ordine operativo. Ogni funzione dispone di un chunk dedicato. Le operazioni che richiedono la soluzione APSIMx locale o una model run sono protette da controlli espliciti.

Questa revisione esegue APSIMx durante il Knit perché `params$run_models` è `true`. La richiesta mantiene `mock = TRUE`: Tool2 e APSIMx vengono eseguiti realmente senza richiedere il servizio dati remoto. Verificare `params$spacing_root` e compilare `Spacing.Tool2` in Visual Studio 2026, configurazione Debug e Any CPU.

**Scopo del chunk `setup`.** Prepara l’ambiente di rendering, carica rSpacing, imposta i parametri globali e stabilisce se le model run possono essere eseguite. Il chunk non produce output visibile, ma crea gli oggetti condivisi da tutte le sezioni successive.

```{r setup, include=FALSE}
knitr::opts_chunk$set(
  echo = TRUE, message = FALSE, warning = FALSE,
  fig.width = 10, fig.height = 6, dpi = 150
)
stopifnot(requireNamespace("rSpacing", quietly = TRUE))
if (utils::packageVersion("rSpacing") < numeric_version("0.10.04")) {
  stop(
    "Questo report richiede rSpacing 0.10.04 o successiva. Versione installata: ",
    as.character(utils::packageVersion("rSpacing"))
  )
}
library(rSpacing)
RUN_MODELS <- isTRUE(params$run_models)
SPACING_ROOT <- normalizePath(params$spacing_root, winslash = "/", mustWork = FALSE)
HAS_LOCAL_RUNTIME <- dir.exists(SPACING_ROOT) &&
  file.exists(file.path(SPACING_ROOT, "src", "Spacing.Tool2", "Spacing.Tool2.csproj"))
OUTPUT_ROOT <- normalizePath(params$output_root, winslash = "/", mustWork = FALSE)
dir.create(OUTPUT_ROOT, recursive = TRUE, showWarnings = FALSE)
APSIMX_TEMPLATE <- file.path(SPACING_ROOT, "examples", "template.apsimx")
result <- run <- cfg <- NULL
```

# Convenzioni

- Gli oggetti vengono costruiti progressivamente e riutilizzati nei chunk successivi.
- I plot meteorologici e geografici sono disponibili anche senza una run.
- I plot di output e suolo vengono prodotti quando `result` è disponibile.
- I chunk di model run usano `mock = TRUE` come impostazione prudente.

## spacing_config()

**Scopo.** Costruisce la configurazione locale usata da rSpacing per trovare la soluzione APSIMx, il progetto `Spacing.Tool2`, il file `spacing.config.json` e la directory delle run.

**Input principali.** Richiede il percorso radice di APSIMx; i percorsi relativi vengono normalizzati.

**Risultato e uso successivo.** Restituisce un oggetto `spacing_config`, riutilizzato dalle funzioni di validazione, costruzione CLI ed esecuzione.

```{r f01-spacing_config}
if (HAS_LOCAL_RUNTIME) {
  cfg <- spacing_config(
    apsim_dir = SPACING_ROOT,
    project = file.path(SPACING_ROOT, "src", "Spacing.Tool2"),
    config_file = file.path(SPACING_ROOT, "spacing.config.json"),
    run_root = file.path(OUTPUT_ROOT, "legacy-runs")

} else cfg <- NULL
```
