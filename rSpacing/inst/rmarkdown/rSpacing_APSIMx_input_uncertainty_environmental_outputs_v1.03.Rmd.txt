# Purpose

This autonomous R Markdown starts from the same five-year 2020-2024 Wheat-Hartog, Maize-B_110 and Soybean-Generic_MG1 rotation used by the stable Morris v1.12. It propagates uncertainty in soil and management **input variables**, not cultivar parameters. Yield and biomass are excluded.

The four environmental responses are analysed separately:

1. final `SoilCtot_kgCha` on the last simulated date;
2. five-year cumulative `N2O_total_kgNha`;
3. five-year cumulative `CO2C_total_kgCha`;
4. five-year cumulative `LeachNO3_kgNha`.

No composite target is calculated.

# Uncertain input factors

All ranges are relative to the quinquennial baseline. The first version uses bounded uniform distributions because no site-specific measurement-error distributions were supplied. Soil hydraulic constraints are reconstructed, not checked only after sampling.

### Che cosa rappresenta il catalogo degli input

Ogni riga è un fattore incerto. `lower` e `upper` sono gli estremi ammessi; per i moltiplicatori, 1 indica la baseline, mentre per gli spostamenti, come `ph_shift`, 0 indica nessuna modifica. La colonna `group` distingue suolo e gestione. Nella v1.03 tutti i fattori seguono una distribuzione uniforme limitata, perché non sono state fornite distribuzioni sperimentali specifiche.

**Come leggere la tabella.** Un intervallo 0,70-1,30 significa una variazione dal -30% al +30%. Un intervallo -0,5-0,5 per il pH significa invece sottrarre o aggiungere fino a mezzo punto. Gli intervalli descrivono l'incertezza assunta, non la sensibilità del modello e non l'importanza finale del fattore.

# Constrained Latin hypercube

### Come vengono generati scenari fisicamente coerenti

Queste funzioni trasformano i numeri LHS in profili e pratiche gestionali utilizzabili da APSIMx. La trasformazione conserva l'ordine fisico `LL15 < DUL < SAT`, mantiene l'acqua iniziale tra `LL15` e `DUL`, impedisce valori negativi di carbonio e azoto e limita il pH. Per l'irrigazione, il target viene mantenuto superiore alla soglia.

Il codice è nascosto perché la parte da comunicare è il principio: il campionamento esplora l'incertezza senza creare profili impossibili. Se uno scenario non supera questi controlli, non viene inviato ad APSIMx.

```{r lhs-functions, include=FALSE}
random_lhs<-function(n,k,seed) { set.seed(seed); out<-matrix(NA_real_,n,k); for(j in seq_len(k)) out[,j]<-(sample.int(n)-runif(n))/n; out }
scale_lhs<-function(U,spec) { X<-sweep(U,2,spec$upper-spec$lower,"*"); X<-sweep(X,2,spec$lower,"+"); colnames(X)<-spec$factor; as.data.frame(X,check.names=FALSE) }
perturb_scenario<-function(x) {
 sp<-soil_profile; layers<-sp$Layers; depths<-vapply(layers,function(z)(z$DepthTop+z$DepthBottom)/2,numeric(1)); z<-depths/max(depths)
 for(i in seq_along(layers)) {
  L<-layers[[i]]
  L$OC<-max(.001,L$OC*x$oc_stock_mult*exp(-x$oc_gradient*z[i]))
  L$BD<-max(.8,min(1.8,L$BD*x$bd_mult))
  ll<-max(.01,min(.35,L$LL15*x$ll15_mult))
  dul<-ll+max(.015,(L$DUL-L$LL15)*x$dul_gap_mult)
  sat<-dul+max(.015,(L$SAT-L$DUL)*x$sat_gap_mult)
  sat<-min(.65,sat); dul<-min(dul,sat-.01); ll<-min(ll,dul-.01)
  L$LL15<-ll; L$DUL<-dul; L$SAT<-sat; L$SW<-ll+x$initial_sw_fraction*(dul-ll)
  L$NO3<-max(0,L$NO3*x$soil_no3_mult); L$NH4<-max(0,L$NH4*x$soil_nh4_mult); L$PH<-max(4,min(9,L$PH+x$ph_shift))
  layers[[i]]<-L
 }
 sp$Layers<-layers; crops<-base_crops
 for(i in seq_along(crops)) {
  m<-crops[[i]]$management
  m$nitrogen_mineral_kg_ha<-max(0,m$nitrogen_mineral_kg_ha*x$mineral_n_mult)
  m$nitrogen_organic_kg_ha<-max(0,m$nitrogen_organic_kg_ha*x$organic_n_mult)
  if(!is.null(m$split_fertiliser)) for(j in seq_along(m$split_fertiliser)) m$split_fertiliser[[j]]$amount_kg_n_ha<-max(0,m$split_fertiliser[[j]]$amount_kg_n_ha*x$split_n_mult)
  if(isTRUE(m$auto_irrigate)) {
   m$irrigation_threshold<-max(.05,min(.90,m$irrigation_threshold+x$irrigation_threshold_shift))
   m$irrigation_target<-max(m$irrigation_threshold+.05,min(.98,m$irrigation_target+x$irrigation_target_shift))
   m$max_irrigation_mm<-max(1,m$max_irrigation_mm*x$max_irrigation_mult)
  }
  crops[[i]]$management<-m
 }
 list(soil_profile=sp,crops=crops)
}
validate_scenario<-function(z) {
 L<-z$soil_profile$Layers
 ok<-all(vapply(L,function(x) is.finite(x$OC)&&x$OC>=0&&is.finite(x$BD)&&x$BD>0&&x$LL15>0&&x$LL15<x$DUL&&x$DUL<x$SAT&&x$SW>=x$LL15&&x$SW<=x$DUL&&x$NO3>=0&&x$NH4>=0&&x$PH>=4&&x$PH<=9,logical(1)))
 list(ok=ok,reason=if(ok) "" else "Invalid constrained soil or management scenario")
}
```

# Output extraction

### Quali risultati ambientali vengono estratti

La tabella definisce in modo esplicito variabile, unità e operazione temporale. Il carbonio del suolo è uno **stock finale**, quindi si usa l'ultimo valore valido alla data conclusiva. N2O-N, CO2-C e nitrato lisciviato sono **flussi**, quindi si sommano tutti i valori giornalieri della rotazione. La tabella `daily` è la sorgente primaria; `sqlite__DailyReport` è il fallback.

**Come leggere le unità.** `N2O_total_kgNha` è espresso come kg di N contenuto in N2O per ettaro, non come kg di N2O e non come CO2 equivalente. `CO2C_total_kgCha` è kg di C contenuto nella CO2. `LeachNO3_kgNha` è N nitrico che lascia il profilo simulato, non una misura diretta della concentrazione in falda.

### Che cosa fa il runner APSIMx

Per ogni scenario il runner crea una cartella indipendente, scrive request e configurazione JSON, avvia `Spacing.Tool2` tramite `dotnet` e legge il risultato. Conserva exit status, log, durata ed eventuale motivo di fallimento. Il codice è nascosto, ma questi metadati rimangono disponibili nelle tabelle diagnostiche.

```{r runner, include=FALSE}
run_uncertainty<-function(run_index,scenario,run_kind="sample") {
 code<-if(run_kind=="baseline") "b" else if(run_kind=="preflight") sprintf("p%02d",run_index) else sprintf("r%03d",run_index)
 run_id<-paste0("u",code); run_dir<-file.path(execution_root,run_id); output_dir<-file.path(run_dir,"o"); weather_dir<-file.path(run_dir,"w"); dir.create(output_dir,recursive=TRUE,showWarnings=FALSE); dir.create(weather_dir,recursive=TRUE,showWarnings=FALSE)

 config<-list(DbApiBaseUrl="http://localhost:8000/api/v1",DbApiKey="",TempWeatherDir=normalize_win(weather_dir,FALSE),OutputDir=normalize_win(output_dir,FALSE),StartYear=START_YEAR,EndYear=END_YEAR,MaxParallelism=1L)
 jsonlite::write_json(request,request_path,auto_unbox=TRUE,pretty=TRUE,digits=NA,null="null"); jsonlite::write_json(config,config_path,auto_unbox=TRUE,pretty=TRUE,digits=NA,null="null")
 args<-c(shQuote(normalize_win(dll_path,TRUE)),"--config",shQuote(normalize_win(config_path,TRUE)),"--request",shQuote(normalize_win(request_path,TRUE)),"--result",shQuote(normalize_win(result_path,FALSE)),"--manifest",shQuote(normalize_win(manifest_path,FALSE))); if(USE_MOCK_WEATHER) args<-c(args,"--mock")

 model_success<-!is.null(result)&&isTRUE(result$success)
 if(!model_success) return(list(model_success=FALSE,outputs_available=FALSE,reason=if(nzchar(stderr_text)) stderr_text else paste("Spacing.Tool2 exit code",exit_status),exit_status=as.integer(exit_status),stderr_path=stderr_path,elapsed_seconds=elapsed))
 env<-extract_environmental_outputs(read_all_tables(result)); c(list(model_success=TRUE,outputs_available=isTRUE(env$available),exit_status=as.integer(exit_status),stderr_path=stderr_path,elapsed_seconds=elapsed),env)
}
```

# Execute uncertainty ensemble

### Che cosa accade nelle 500 simulazioni

Per ogni riga del LHS il blocco ricostruisce suolo e gestione, valida il profilo, esegue APSIMx e registra i quattro output. Salva `uncertainty_runs.csv`, l'audit dei profili e un file separato per le run fallite. L'analisi statistica prosegue soltanto se almeno l'80% degli scenari, e comunque almeno 30, è completo.

```{r execute-ensemble, include=FALSE, eval=params$execute_runs}
run_rows<-vector("list",nrow(uncertainty_design)); profile_audit<-vector("list",nrow(uncertainty_design))
for(i in seq_len(nrow(uncertainty_design))) {
 x<-as.list(uncertainty_design[i,input_spec$factor,drop=FALSE]); z<-perturb_scenario(x); ck<-validate_scenario(z)
```

# Uncertainty summaries and rankings

### Come vengono stimati incertezza e importanza

Le funzioni calcolano statistiche descrittive, PRCC e coefficienti di regressione standardizzati. Il PRCC usa i ranghi e misura l'associazione monotona tra un input e un output dopo aver controllato gli altri input. Il bootstrap ripete il calcolo su campioni ricampionati per costruire l'intervallo di confidenza al 95%.

```{r analysis-functions, include=FALSE}
output_names<-c("soil_c_final_kgCha","n2o_cumulative_kgNha","co2c_cumulative_kgCha","leach_no3_cumulative_kgNha")
summary_one<-function(y,nm) data.frame(output=nm,n=length(y),mean=mean(y),sd=sd(y),cv=sd(y)/abs(mean(y)),min=min(y),p05=quantile(y,.05),p25=quantile(y,.25),median=median(y),p75=quantile(y,.75),p95=quantile(y,.95),max=max(y),row.names=NULL)
prcc_one<-function(X,y) {
 RX<-apply(X,2,rank,ties.method="average"); ry<-rank(y,ties.method="average"); out<-numeric(ncol(RX))
 for(j in seq_len(ncol(RX))) { others<-setdiff(seq_len(ncol(RX)),j); rxres<-residuals(lm(RX[,j]~RX[,others,drop=FALSE])); ryres<-residuals(lm(ry~RX[,others,drop=FALSE])); out[j]<-cor(rxres,ryres) }
 out
}
src_one<-function(X,y) { Z<-as.data.frame(scale(X)); fit<-lm(as.numeric(scale(y))~.,data=Z); unname(coef(fit)[-1]) }
bootstrap_prcc<-function(X,y,B,seed) { set.seed(seed); ans<-matrix(NA_real_,B,ncol(X)); for(b in seq_len(B)) { ii<-sample.int(nrow(X),replace=TRUE); ans[b,]<-tryCatch(prcc_one(X[ii,,drop=FALSE],y[ii]),error=function(e)rep(NA_real_,ncol(X))) }; ans }
```

### Come vengono prodotti i quattro ranking

Il blocco analizza separatamente Soil C finale, N2O-N, CO2-C e nitrato lisciviato. Per ciascun output calcola PRCC, intervallo bootstrap, coefficiente standardizzato e rango basato sul valore assoluto del PRCC. Un PRCC positivo indica che l'output tende ad aumentare al crescere dell'input; uno negativo indica una diminuzione. Il valore assoluto descrive la forza, mentre il segno descrive la direzione.

```{r calculate-rankings, include=FALSE}
X<-as.matrix(analysis_data[,input_spec$factor,drop=FALSE]); summaries<-do.call(rbind,lapply(output_names,function(nm) summary_one(analysis_data[[nm]],nm)))
rankings<-list()
for(o in seq_along(output_names)) { nm<-output_names[o]; y<-analysis_data[[nm]]; pr<-prcc_one(X,y); sr<-src_one(X,y); boot<-bootstrap_prcc(X,y,as.integer(params$bootstrap_replicates),as.integer(params$seed)+o); tab<-data.frame(output=nm,factor=input_spec$factor,group=input_spec$group,prcc=pr,prcc_low=apply(boot,2,quantile,.025,na.rm=TRUE),prcc_high=apply(boot,2,quantile,.975,na.rm=TRUE),standardized_regression=sr,stringsAsFactors=FALSE); tab$importance_rank<-rank(-abs(tab$prcc),ties.method="min"); rankings[[nm]]<-tab[order(tab$importance_rank),] }
importance<-do.call(rbind,rankings)
write.csv(summaries,file.path(analysis_root,"environmental_output_summary.csv"),row.names=FALSE); write.csv(importance,file.path(analysis_root,"input_importance_ranking.csv"),row.names=FALSE)
for(nm in output_names) write.csv(rankings[[nm]],file.path(analysis_root,paste0("prcc_",nm,".csv")),row.names=FALSE)
```

# Interpretation notes

- `SoilCtot_kgCha` is selected only at the last simulated date.
- N2O-N, CO2-C and nitrate leaching are summed across all daily records of the five-year rotation.
- `LeachNO3_kgNha` is nitrate-N leaving the simulated soil profile, not a direct prediction of nitrate reaching the groundwater table.
- The four outputs retain their native APSIMx units and are ranked separately.
- The synthetic demonstration soil profile remains the baseline. Results quantify uncertainty around this scenario and must not be interpreted as site-calibrated uncertainty without observed input distributions.
