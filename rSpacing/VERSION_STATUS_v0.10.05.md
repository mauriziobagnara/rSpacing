# rSpacing 0.10.05 version status

- Base: stable rSpacing 0.10.04.
- Scope: graphical API extension only.
- Added public functions: `plot_spacing_atlas()`, `plot_spacing_yield()`, `plot_spacing_irrigation()`, `plot_spacing_fertilisation()`, `plot_spacing_soil_carbon()`, and `plot_spacing_comparison()`.
- Stable C# reference: complete Spacing.Tool2 solution 0.09.05, unchanged and not included.
- Existing run, request, run-spec, map, result-accessor, and output-import APIs are unchanged.
- This version is a candidate pending `devtools::test()`, `devtools::check()`, and vignette rendering in the target RStudio environment.

## Executable vignette

- Added an executable workflow vignette with evaluated configuration, weather, soil, management, run-spec, result, and plotting examples.
- The external Tool2/APSIMx process is optional during package checks.
- Result sections require a real `spacing_result` fixture generated by `inst/scripts/build_reference_fixture.R`; no fabricated APSIMx output is bundled.

## Packaging correction

- Removed the blank record between `Config/roxygen2/version` and `VignetteBuilder` in `DESCRIPTION`.
- `DESCRIPTION` is now one valid DCF record and can be parsed by `devtools::document()` and `R CMD build`.

## Test-suite corrections

- Corrected one-row and multi-row parameter-catalogue JSON round-trips.
- Restored `--run-spec` CLI argument construction expected by the stable run-spec tests.
- Removed all four warnings reported by the specialised-plot tests.

## Windows path correction

- `build_spacing_args()` now validates the run-spec path and normalises it with base R `normalizePath(..., winslash = "/")`.
- This prevents a false test failure caused solely by an equivalent Windows 8.3 path such as `MAURIZ~1.BAG`.

## Vignette build correction

- Corrected the `weather-edit` chunk: date limits are derived from the actual `year` and `day` columns in `minimal.met`.
- The previous empty subset was caused by `min(NULL)`/`max(NULL)`, not by the weather reader or `subset_spacing_met()`.
